# Consolidação de Dados de Vendas

---

## Requisitos

- Python 3.8+
- `pandas`
- `openpyxl`

Instale as dependências com:
```bash
pip install pandas openpyxl
```

---

## Como Executar

Coloque o arquivo `main.py` na mesma pasta que os dois arquivos de origem e execute:

```bash
python main.py
```

O arquivo `Relatório de Vendas.xlsx` será gerado na mesma pasta.
